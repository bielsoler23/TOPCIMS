# TOPCIMS

Web catàleg de cims fet per excursionistes. Projecte de l'assignatura de Disseny (2n de DAW).

## Pàgines

- `index.html` → pàgina d'inici
- `login.html` → iniciar sessió
- `registre.html` → crear un compte

## Tecnologies

- HTML
- Tailwind CSS (CDN)
- Google Fonts: Oswald i Inter
- Disseny fet abans a Figma

## Com veure-ho

Web publicada: https://bielsoler.cat/topcims/

També pots obrir `index.html` al navegador.
