# TOPCIMS

Web catàleg de cims fet per excursionistes.

## Pàgines

- `index.html` → pàgina d'inici
- `login.html` → iniciar sessió
- `registre.html` → crear un compte

## Tecnologies

- HTML
- Tailwind CSS (CDN)
- Google Fonts: Oswald i Inter
- Disseny fet abans a Figma

## Com veure-ho

Obre `index.html` al navegador.
